# Media and Embeds

Help articles can include rich content without custom React work.

## Screenshots

Use normal markdown image syntax:

```md
![Project overview example](/help/project-overview.svg)
```

## Videos

Use a markdown link whose label starts with `video:`:

```md
[video: Project creation walkthrough](/help/project-creation.mp4)
```

## Embeds

Use a markdown link whose label starts with `embed:`:

```md
[embed: External process board](https://example.com)
```
