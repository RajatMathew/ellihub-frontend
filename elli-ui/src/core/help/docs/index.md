# Help Center Overview

Use the Help Center for page-level instructions, project workflows, and finance process notes. Articles are written in markdown so the support team can add headings, lists, tables, images, videos, and embedded references without changing React components.

## Supported content

| Content type | Markdown pattern |
| --- | --- |
| Image | `![Alt text](/path/to/image.png)` |
| Video | `[video: Walkthrough title](/path/to/video.mp4)` |
| Embed | `[embed: External reference](https://example.com)` |
| Callout | Start a paragraph with `>` |

> Keep articles task-focused. A user should know what to do next after scanning the first screen.
