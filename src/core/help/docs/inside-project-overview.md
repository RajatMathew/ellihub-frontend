# Inside a Project

The project workspace brings together commercial activity, files, and project controls.

## Common areas

- **Overview** shows project financials, schedule status, team members, and key contract details.
- **RFQs** tracks requests for quotes and vendor responses.
- **Invoices** tracks billing and payment details.
- **Purchase Orders** manages committed costs.
- **Files** stores project documents.
