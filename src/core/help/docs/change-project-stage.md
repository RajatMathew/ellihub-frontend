# Changing the Stage

Project stages help teams scan what needs attention and separate active jobs from completed or archived work.

## Stage change checklist

1. Open the project.
2. Review open RFQs, invoices, and purchase orders.
3. Update the stage from the project edit screen.
4. Save and return to the project overview.

> Before marking a project complete, confirm all billing and cost items are reconciled.
