# Editing a Project

Use edit mode for project metadata changes such as name, address, stage, owner, and schedule fields. Financial documents remain linked to the same project after edits.

## Recommended checks

- Review the project code before saving.
- Confirm the stage change is intentional.
- Verify contacts and team members after ownership changes.

## Notes

Changes are visible in project activity history when the backend provides audit events.
